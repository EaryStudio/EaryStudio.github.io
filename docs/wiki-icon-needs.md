## 기본 아이콘 적용 완료

제공받은 `UI Logo3.png`의 왼쪽 기록장은 통계 22개에, 오른쪽 유물은 박물관과 12개 보상 단계에 공통 적용했습니다. 현재 표시상 빈 아이콘을 채우기 위해 추가로 준비할 그림은 없습니다. 원본 64×64 시트는 변경하지 않고 각 32×32 영역을 표시합니다.

## 별도 그림이 필요하지 않은 항목

- 상점 3개: 골드·두카린·순환석 통화 아이콘을 각각 재사용합니다.
- 손재주: 절도 스킬 아이콘을 재사용합니다.
- 상점 오퍼 69개: 판매 아이템의 기존 아이콘을 자동 재사용하도록 적용했습니다.
- 시스템 4개: 상업·강화·회화·작문의 스킬 아이콘을 자동 재사용하도록 적용했습니다.
- 게임 내 가이드 24개: 관련 스킬 또는 분류에 본문으로 넣었습니다. 가이드 전용 그림은 필요하지 않습니다.
- 규칙 5개: 독립 탐색 탭에서 제외했습니다.

박물관 보상 단계별 그림은 선택 사항입니다. 단계는 5·10·20·50·100·150·200·300·400·450·500·600개 제출입니다.
